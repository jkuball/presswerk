# Vendored Gitmoji catalog

`catalog.rs` contains the fields used from
[`packages/gitmojis/src/gitmojis.json`](https://github.com/carloscuesta/gitmoji/blob/c7e067f43a33c5d9d42450314977efa409101308/packages/gitmojis/src/gitmojis.json)
at upstream commit `c7e067f43a33c5d9d42450314977efa409101308`.

The catalog is bundled as Rust data so commit analysis is deterministic, works offline, and is
included by the Cargo source filter. Upstream licenses this material under the MIT license in
`LICENSE`.
