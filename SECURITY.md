# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues or discussions.

Use [GitHub private vulnerability reporting](https://github.com/jkuball/presswerk/security/advisories/new)
to send the maintainers a private report. Include the affected version or commit, the expected
impact, reproduction steps, and any suggested mitigation when available.

The maintainers will review the report privately and coordinate disclosure and remediation with
the reporter.

## Supported versions

Presswerk is pre-1.0 software. Security fixes are provided for the latest release and the current
`main` branch only.
